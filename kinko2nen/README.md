# 金庫二年

「禁錮二年」だと思ったら「金庫二年」だった、という一発ネタの短編ゲームです。
ブラウザだけで動きます。1プレイ 5〜10 分、セーブ不要。

遊ぶ： https://katomi95.github.io/ukemi-repo/kinko2nen/

## 流れ

1. **OP** — 「判決。被告人を禁錮二年に処す」の「禁錮」に訂正線が入り、「金庫」に直される
2. スポットライトが点くと、主人公は巨大な金庫の着ぐるみを着せられている
3. **本編** — 現金・実印・契約書・USBメモリ・合鍵・絶対なくしたらまずいやつ・私物…
   次々に物を預けられる。プレイヤーは毎回「入れる／拒否する／これは金庫の仕事なのか聞く」を選ぶ
4. **刑期満了** — そしてオチ。最後に勤務評定が出ます

周囲の人間は誰ひとり疑問を持ちません。主人公だけが最後までツッコミ役です。

## 操作

- **クリック** または **Space / Enter** で会話を送る（送り中にもう一度で全文表示）
- 選択肢は **クリック** または **1〜3 キー**
- 右上の **♪** で音の ON / OFF（音がなくても成立します）

## 技術メモ

- `index.html` 1ファイルで完結。外部ライブラリ・外部アセット・ビルドなし
- 画面は HTML / CSS / インライン SVG、効果音は Web Audio API で合成
- PC 向け。ウィンドウ幅に合わせて 16:10 の画面が拡大縮小します
- GitHub Pages にそのまま置けます

ローカルで遊ぶ場合は `index.html` をブラウザで開くだけです。
